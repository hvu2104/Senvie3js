# Senvie 3D Booth

Mô hình 3D phác thảo booth exhibition **Hiểu Da Mình** (SenvieLab × SenvieClub), dựng bằng Three.js.

- Xem booth 3D: https://hvu2104.github.io/Senvie3js/
- Chơi game Sen Quest (bản thử): https://hvu2104.github.io/Senvie3js/game/ — hướng dẫn trong `game/HUONG_DAN.md`
- Kéo chuột để xoay, cuộn để zoom, chuột phải để di chuyển. Các nút phía trên đổi chương (Nhận ra / Thấu hiểu / Duy trì) và góc nhìn.
- `index.html` là một file duy nhất: ảnh, font, logo nhúng sẵn; thư viện three@0.160.1 tải từ jsDelivr.

Đây là bản concept, kích thước và nội dung là đề xuất, chưa chốt.

## Mô phỏng triển lãm "Giải mã làn da"

- Xem: https://hvu2104.github.io/Senvie3js/trien-lam/
- Phòng giả định 40 × 24 m, 1 cửa vào, 1 cửa ra: Check-in → Zone 1 Nỗi sợ → Zone 2 Hiểu da → Zone 3 Hiểu mình → Photobooth, khu phụ huynh ở giữa.
- Nút "Núm xoay" (hoặc bấm vào bàn xoay) để thử bàn xoay hormone 9 → 18 tuổi. Số liệu chỉ để minh hoạ.
- `trien-lam/index.html` là một file duy nhất, three@0.160.1 tải từ jsDelivr.
